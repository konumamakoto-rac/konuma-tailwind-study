1. ホバー（状態バリアント）

hover: のようなバリアントをクラスの先頭に付けると、その状態のときだけ効きます。 transition を併せて付けると、変化がなめらかになります。

色を変える

カーソルを乗せてください。

hover:bg-sky-50 transition-colors

浮き上がる

影と位置を同時に変えます。

hover:-translate-y-1 hover:shadow-lg

拡大する

duration を省くと既定 150ms。

hover:scale-105 transition

hover 以外の状態も同じ書き方

hover: / focus: / active: / disabled: / dark: — すべて「状態: + 通常のクラス」

2. 入れ子（親子・兄弟要素への対応）

「親にホバーしたら子を変えたい」「隣の入力欄の状態で表示を変えたい」—— クラスは自分自身にしか効かないので、 group / peer / 任意バリアントで橋渡しします。

group — 親のホバーで子を変える

親に group、子に group-hover: を付けます。

📁 🚀 カード全体がリンク どこにホバーしても、アイコン・丸・文字・矢印が同時に変わる →

親: group ／ 子: group-hover:bg-sky-500 group-hover:translate-x-1
アイコン差し替え: 📁 に group-hover:hidden ／ 🚀 に hidden group-hover:block

peer — 兄弟要素の状態を見る

先に置いた要素に peer、 後ろの要素に peer-*: を付けます。

メールアドレスの形式で入力してください。

peer / peer-checked: / peer-user-invalid: / peer-focus:

子要素をまとめて指定する

子ひとつずつにクラスを書かず、親から一括で指定できます。

space-y-2（子の間に余白）

5. テーマ変数（カスタム色）

Tailwind に無い色は src/style.css の @theme に --color-名前 を書けば追加できます。v4 では tailwind.config.js は不要です。

単色（段階なし）

--color-brand: oklch(0.55 0.19 253); と書くと bg-brand / text-brand / border-brand が一度に使えるようになります。

bg-brand
bg-accent
bg-ink
bg-paper / text-ink

段階つき（-50 〜 -950）

--color-matcha-50 … --color-matcha-950 のように連番で定義すると、 デフォルト色と同じ感覚で濃淡を選べます。

matcha（抹茶）

sakura（桜）

既存の仕組みと全部組み合わせられる

カスタム色も、標準色とまったく同じように hover: / dark: / md: / 不透明度 /40 が効きます。

bg-accent/25（不透明度）
dark: と組み合わせた例（ライト=薄い抹茶 / ダーク=濃い抹茶）

色以外のテーマ変数

名前空間ごとに、定義できるクラスが決まっています。

--color-*
bg-* / text-* / border-* / ring-* / from-*
--font-*
font-*（この見出しは font-display）
--radius-*
rounded-*（このカードは rounded-card）
--text-*
text-*（文字サイズ）
--spacing
p-* / m-* / gap-* の1単位（既定 0.25rem）

メモ: 定義しただけで使っていないテーマ変数は、ビルド後の CSS に含まれません。 常に出力したいときは @theme static を使います。
